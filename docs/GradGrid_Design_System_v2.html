Badges — Bifurcated into 5 Types

Badges are grouped by semantic purpose, not just colour. Each type has distinct shape, weight, and usage rules. Always pair colour with a label or icon — never colour alone as the sole indicator.

Type 1 — Status Badges (entity state)
Active Inactive Pending Archived Processing Encrypted Present Absent Late Paid Overdue Partial Enrolled Transferred

Used on: Student status, attendance records, fee payment status, admission pipeline status, staff employment state.

Type 2 — Category Badges (classification)
General OBC SC ST CBSE ICSE State Board New Student Old Student Scholarship Grade 8 Section B Hindi Medium English Medium

Used on: Student category, board, medium, class, section, scholarship type. Never for state — use Status badges for that.

Type 3 — Count Badges (numeric indicators)
Notifications 12
Pending Approvals 7
Import Errors 14
Comments 3
Students Selected 247
Type 4 — Priority Badges (urgency)
High Priority Medium Low Coming Soon

Used on: Audit log severity, approval urgency, support tickets, fee overdue escalation. Coming Soon badge is a Priority variant.

Type 5 — Role Badges (user identity)
Owner Admin Teacher Accountant HR Receptionist Librarian Custom Role

Used on: User lists, table rows, audit logs, notification senders. Each role has a unique colour pairing for quick scanning.

Stat Cards — Redesigned

The left-rail strip (4px, full-height) is the signature element — referencing the ruled margin of a school register. The subtle circular watermark in the bottom-right corner echoes the rail's colour at near-zero opacity. No box shadows — structured borders and the accent strip carry the visual hierarchy.
